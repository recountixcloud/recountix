Official WhatsApp Business API

Meta Cloud API

Sends through your connected Meta WhatsApp Business phone number using an approved message template. A backend deployment and Meta setup are required.

Default template: recountix_payment_reminder, language en. It must be approved in Meta and contain exactly three body placeholders: customer name, amount, business name.

Reminder Day Setup

Choose how many days after a reminder the next reminder should be due. This value is used as the default interval for customer reminder setup.

Important: saving this interval does not itself run a background scheduler. Fully automatic official API delivery requires a server-side scheduled job that checks due customers and calls the WhatsApp API; the current manual reminder flow opens WhatsApp Web.

Enable the official API

  1. Create/configure a WhatsApp Business Platform app in Meta and verify the sender phone number.
  2. Create and get approval for the template recountix_payment_reminder with three body variables.
  3. Deploy the included whatsapp-send Supabase Edge Function.
  4. Set the server-side secrets WHATSAPP_ACCESS_TOKEN, WHATSAPP_PHONE_NUMBER_ID, and optionally WHATSAPP_GRAPH_API_VERSION.
  5. Deploy with JWT gateway verification disabled only because the function validates Recountix's own session token itself: supabase functions deploy whatsapp-send --no-verify-jwt.
The API button will return a configuration error until the Edge Function is deployed and the Meta secrets/template are ready. WhatsApp Web works independently of the API.
